## ✨ О проекте

**Guess The Number** — это компактная браузерная игра без сборщиков и зависимостей.  
Интерфейс оформлен в современном стиле: тёмный фон, мягкое свечение, glassmorphism-карточки и адаптивная сетка для мобильных устройств.

Игрок вводит число, а игра отвечает:

- **«Слишком мало 🔽»** — если нужно подняться выше;
- **«Слишком много 🔼»** — если стоит снизить ставку;
- **победным сообщением** — когда число найдено;
- **температурой хода** — насколько близко число к цели;
- **сужающимся диапазоном** — где ещё может быть ответ.

## 🚀 Быстрый старт

Открой `index.html` в браузере — и можно играть.

Если нужен локальный сервер:

```bash
python3 -m http.server 4173
```

Затем перейди по адресу:

```text
http://127.0.0.1:4173/
```

---

## 🕹️ Как играть

1. Введи целое число в текущем диапазоне.
2. Нажми **«Проверить»**.
3. Следуй подсказкам игры.
4. Найди число как можно быстрее.
5. Следи за историей попыток, подсказками «горячо / холодно» и сужающимся диапазоном.
6. Выбери сложность или запусти **Daily Challenge**.
7. Нажми **«Сыграть ещё»**, чтобы начать новый раунд, или **«Сдаться»**, чтобы раскрыть число.

> По умолчанию диапазон — от **1 до 100**.

## 🌟 Возможности

| Возможность | Описание |
| --- | --- |
| 🎯 Подсказки после каждого хода | Игра сообщает, загаданное число больше или меньше введённого. |
| 🧭 Уровни сложности | Easy, Normal, Hard, Expert и Daily меняют лимит попыток и формат подсказок. |
| ⚙️ Настраиваемый диапазон | Можно выбрать собственные значения «от» и «до». |
| 🏆 Рекорды по режимам | Лучший результат сохраняется в `localStorage` отдельно для диапазона и сложности. |
| 📱 Адаптивный дизайн | Интерфейс удобно выглядит на десктопе и мобильных экранах. |
| 🧾 История попыток | Последние ходы отображаются списком, чтобы легче держать стратегию. |
| 🌡️ Горячо / холодно | Игра показывает, насколько близко число к цели. |
| 📉 Сужающийся диапазон | После каждого хода видно, где ещё может быть ответ. |
| 📊 Статистика игрока | Сохраняются игры, процент побед, серия и среднее число попыток. |
| 🗓️ Daily Challenge | Ежедневный режим генерирует стабильное число для текущей даты. |
| ♿ Доступность | Используются label, aria-атрибуты, focus-состояния и live-region для статуса игры. |

## 🧩 Структура проекта

```text
.
```

## 🎨 Дизайн

Ключевые элементы оформления:

- тёмная неоновая палитра;
- градиентные акценты;
- glassmorphism-карточки;
